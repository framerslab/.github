# Support

This page covers every public repository in the framerslab organization that has no support page of its own.

- **Questions and discussion:** [Discord](https://wilds.ai/discord). GitHub issues are for bugs and feature requests.
- **Documentation:** the repository's README; for AgentOS and its packages, [docs.agentos.sh](https://docs.agentos.sh)
- **Bugs and feature requests:** the repository's issues. Search the existing issues first. A bug in the AgentOS runtime belongs in [agentos](https://github.com/framerslab/agentos/issues/new/choose).
- **Security issues:** report privately as the [security policy](https://github.com/framerslab/.github/blob/main/.github/SECURITY.md) describes, never in a public issue.
- **Commercial, partnership or sponsorship inquiries:** team@frame.dev

To contribute, see [CONTRIBUTING.md](https://github.com/framerslab/.github/blob/main/CONTRIBUTING.md).
